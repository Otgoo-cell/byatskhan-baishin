# Бяцхан Байшин

Гэр бүлээ хөөрхөн амьтан болгоод амьд бяцхан байшиндаа нүүлгээрэй. Амьтад өөрсдөө ажилдаа явж, хоол хийж, тоглож, орой нь хамт унтдаг 3D тоглоомон байшин.

**Тоглох:** https://otgoo-cell.github.io/byatskhan-baishin/

- iPhone: Safari-аар нээгээд ⬆️ Хуваалцах → «Нүүр дэлгэцэд нэмэх»
- Android: Chrome-оор нээгээд «Суулгах» товчийг дарна
